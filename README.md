# Modern Todo App

A feature-rich, responsive todo application with multiple themes, drag & drop functionality, and time-based reminders.

## Features

### Core Functionality
- ✅ Add, edit, and delete todos
- ✅ Mark todos as complete/incomplete
- ✅ Filter todos (All, Active, Completed)
- ✅ Drag & drop reordering
- ✅ Local storage persistence

### Themes
- 🎨 **Gradient Theme** - Beautiful purple gradient with glassmorphism
- ☀️ **Light Theme** - Clean, professional light mode
- 🌙 **Dark Theme** - Modern dark mode with subtle accents

### Reminders & Notifications
- ⏰ Set time-based reminders for todos
- 🔔 Browser notifications when reminders are due
- 🔊 Audio alarm with custom sound
- 📅 Smart time formatting (today vs. future dates)
- 🚨 Visual indicators for overdue reminders

### User Experience
- 📱 Fully responsive design
- ⌨️ Keyboard shortcuts
- 🎯 Smooth animations and transitions
- 🔒 XSS protection and input validation
- 📊 Real-time statistics

## Usage

1. **Adding Todos**: Type in the input field and press Enter or click +
2. **Setting Reminders**: Click the ⏰ button, set time, then add todo
3. **Filtering**: Use All/Active/Completed tabs
4. **Reordering**: Drag and drop todos to reorder
5. **Themes**: Click the theme button in header to cycle through themes

## Keyboard Shortcuts

- `Enter` - Add new todo
- `Escape` - Clear input field
- `Ctrl/Cmd + A` - Toggle all todos
- `Ctrl/Cmd + Shift + C` - Clear completed todos

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, flexbox, animations
- **Vanilla JavaScript** - ES6+ features, Web APIs
- **Web Audio API** - Custom alarm sounds
- **Notification API** - Browser notifications
- **Local Storage** - Data persistence

## Browser Support

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## Installation

1. Clone or download this repository
2. Open `index.html` in your browser
3. Start organizing your tasks!
